DOSEBUDDY / PRACTICE MODE

Try DoseBuddy.

This is the app’s Flutter interface, running in your browser. The medications and history are fictional, and there’s no sign-up.

A few things to try

  1. Record a dose, then correct it in Insights → tools → Dose Review.
  2. Open the calendar and compare the week and month adherence charts.
  3. Add a symptom, log a refill, or create a medication with the unit selector.
  4. Preview and download a doctor report with symptoms included.

Changes stay in this browser. Use the Reset button to restore the sample records. Please use fictional information only.

What differs from the phone app?

Label uploads use browser text recognition. The first scan downloads a model and may take a moment; you can also try sample label text. Every result needs your review.

Scheduled phone notifications are previewed here but aren’t delivered. Care Circle permissions can be explored, but this demo sends no invitations or text messages. Connected medication sharing is still being built.
